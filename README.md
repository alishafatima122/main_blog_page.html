# 🎓 Online Education Information Page

A beginner-friendly HTML project that provides an overview of online education, its benefits, and a comparison between online and traditional learning. The project also demonstrates the use of navigation links, tables, lists, and basic CSS styling.

## ✨ Features

- Navigation menu
- Introduction to online education
- Advantages of online learning
- Comparison table between online and traditional education
- External page links
- Simple and clean design
- Basic table styling with CSS

## 🛠️ Technologies Used

- HTML5
- CSS3 (Internal Styling)

## 📂 Project Structure

```
Online-Education-Information/
│
├── index.html
├── home.html
├── contact.html
├── resources.html
└── README.md
```

## 🎯 Learning Objectives

This project was created to practice:

- HTML document structure
- Navigation menus
- Hyperlinks and anchor tags
- Headings and paragraphs
- Text formatting (`<strong>` and `<em>`)
- Unordered lists
- Creating and styling tables
- Internal CSS

## 🚀 How to Run

1. Download or clone this repository.
2. Open `index.html` in any web browser.
3. Use the navigation menu and links to explore the webpage.
